It reads live project context, executes PyQGIS and Processing workflows, designs print layouts and reusable layout templates, preserves per-project history, exports Markdown/PDF audit trails, surfaces every question the agent asks as an answerable card, and asks before destructive operations. It uses an existing Claude Code or Codex CLI login, with bundled GIS skills, verification rules, and a local authenticated MCP bridge.
